# Basic Weather App

## Description
A Python-based weather application that allows users to enter a city name and view its current weather information.

## Features
- Search weather by city name
- Display current temperature
- Display weather conditions
- Display humidity
- Display wind speed
- Simple and user-friendly interface

## Technologies Used
- Python
- Tkinter
- Weather API
- Requests library

## How to Run
1. Make sure Python is installed.
2. Install the required libraries.
3. Open the project in PyCharm or any Python IDE.
4. Run `main.py`.
5. Enter a city name to view its weather information.
