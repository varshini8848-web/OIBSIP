# Random Password Generator

## Description

A simple Python-based Random Password Generator that creates strong and secure passwords using a combination of letters, numbers, and special characters.

## Features

- Generates random passwords
- Creates strong and unique passwords
- Uses uppercase and lowercase letters
- Includes numbers and special characters
- Easy to use
- Simple and user-friendly interface

## Technologies Used

- Python
- Tkinter
- Random Module
- String Module
