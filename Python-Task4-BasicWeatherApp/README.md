# Basic Weather App

## Description
A Python-based weather application that allows users to enter a city name and view its current weather information.

## Features
- Search weather by city name
- Display current temperature
- Display weather conditions
- Display humidity
- Display wind speed
- Simple and user-friendly interface

## Technologies Used
- Python
- Tkinter
- Weather API
- Requests library
